# Astra OS Desktop Design

## World

The desktop is an obsidian observatory: a quiet charcoal field with precise pools of violet and cyan system light. Window chrome is lightweight and architectural. Blur is reserved for the taskbar, Start menu, and floating system surfaces that genuinely sit above the wallpaper.

## Typography

The desktop uses Segoe UI Variable/Segoe UI for familiar Windows-hosted readability. Cascadia Mono/Consolas is reserved for Almanac, paths, process data, and system measurements.

## Color and material

- Background: near-black graphite with low-contrast radial light.
- Primary system accent: cool violet.
- Secondary live-state accent: cyan.
- Host accent: amber, always paired with the word HOST.
- Virtual accent: violet, paired with VIRTUAL where origin can be ambiguous.
- Windows use opaque charcoal content under a lightly translucent title bar.

## Interaction

Windows focus by pointer and rise predictably. Title bars drag with pointer capture, double-click maximizes, and controls remain keyboard accessible. Desktop resources select on click and reveal the exact Almanac command instead of bypassing the command model. Almanac alone opens directly.

## Motion

Windows enter with a short scale-and-lift. Start and tray surfaces use a restrained clip/blur reveal. Reduced-motion disables spatial transitions without removing state changes.
